# Comandos para ejecutar localmente (desde el host, NO desde contenedor)

## Requisitos
- PostgreSQL debe estar corriendo en `localhost:5432`
- Credenciales: `admin:secret_password_tfg`
- Para seed: establecer variable DATABASE_URL con localhost

## Cuenta creada por seed
- Email: `admin@uclm.es`
- PasswordTemporal: `Admin123!` (NO cumple política - requiere cambio obligatorio)

## Migraciones
```powershell
$env:DATABASE_URL = "postgresql://admin:secret_password_tfg@localhost:5432/identity_vault"
npx prisma migrate deploy --schema=./prisma/schema.prisma
```

## Seed
```powershell
$env:DATABASE_URL = "postgresql://admin:secret_password_tfg@localhost:5432/identity_vault"
npx tsx src/prisma/seed.ts
```
